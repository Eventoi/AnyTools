# Game Save Backup

Программа для управления конфигурациями резервного копирования игровых сохранений

### Основные функции

- Сканирование и автоматический импорт существующих конфигураций из папки бэкапа сэйвов
- Автоматическое создание папки для хранения сэйвов по имени конфигурации
- Отслеживание процесса игры и создание бэкапа при ее закрытии
- Создание архивов предыдущих бэкапов не более 10 штук
- Режим Dark Souls для создания бэкапа выбранного файла каждые 15 минут
